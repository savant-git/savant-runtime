# UNIVERSAL INSTANCE STRUCTURE

STATUS: CANON
AUTHORITY: USER DIRECTIVE

Every object is an instance.

Every instance may compose other instances.

Every hierarchy level uses the same structural model.

Files are projections.

Authority lives in instance composition, segues, and policies.

The content hierarchy is:

character
line
snippet
script
module
service
application

The identity hierarchy is:

iota
shard
trait
quirk
prodigal
exile
innate
gate
obelisk

No hierarchy type receives a special storage model.

Only semantics differ.
