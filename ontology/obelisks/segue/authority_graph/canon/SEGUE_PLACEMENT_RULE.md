# SEGUE PLACEMENT RULE

STATUS: CANON
AUTHORITY: USER DIRECTIVE

The ontology root contains only edifice roots.

Current rule:

ontology/
└── obelisks/

Shared ontology infrastructure does not live directly inside ontology/.

Shared ontology infrastructure belongs inside the segue beneath obelisks:

ontology/obelisks/segue/

All future non-edifice folders must be placed under the correct segue folder for their edifice level.

No direct ontology/segue folder is valid.
