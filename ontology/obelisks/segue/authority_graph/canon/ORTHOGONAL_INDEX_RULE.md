# ORTHOGONAL INDEX RULE

STATUS: CANON
AUTHORITY: USER DIRECTIVE
BASELINE: sav062726.txt

Hierarchy determines ownership.

Indexes determine discovery.

Indexes never own authority.

Indexes only reference authoritative instances.

Indexes are projections.

Deleting an index must never delete an instance.

Regenerating an index must be deterministic.
