# PRIMARY ARCHITECTURAL LAW

Version: 1.0.0
Status: Accepted
Authority: Current User Directive
Scope: Global
Supersedes: INSTANCE_FIRST_MODULARITY.md where conflict exists

## Law

Savant must minimize authoritative substance while maximizing emergent capability.

Everything that can be expressed as a reusable instance must be expressed as a reusable instance.

Everything that can be derived through canonical modular moods must be derived through those moods rather than through duplicated substance.

Atomic elements are the only directly substantiated material.

Everything above the atomic level is identity, reference, composition, occupancy, relationship, controlled variation, manifestation, ordering, or governed emergence.

## Canonical Moods

1. Anima
2. Weld
3. Kiln
4. Graft
5. Aria
6. Mantle
7. Fulcrum
8. Echelon
9. Ascent

## Construction Priority

Before creating new authoritative substance:

1. reuse an existing instance
2. reuse an existing primitive
3. extend an existing Weld
4. resolve through an existing Mantle
5. occupy an existing Graft slot
6. derive through an existing Kiln
7. vary through an existing Aria
8. mediate through an existing Fulcrum
9. order through an existing Echelon
10. derive through an existing Ascent
11. create a new instance from existing authority
12. substantiate genuinely new authority

Every newly substantiated element must prove why the preceding mechanisms were insufficient.

## Minimal Footprint

Every implementation must minimize:

1. authoritative footprint
2. storage footprint
3. code footprint
4. dependency footprint
5. runtime footprint
6. migration footprint
7. validation footprint
8. cognitive footprint
9. recovery footprint

Footprint reduction may never weaken correctness, determinism, authority, auditability, recoverability, security, observability, compatibility, or extensibility.

## Construction Mechanisms

Exactly three construction mechanisms exist:

1. additive slot capability
2. two-mood fusion
3. Weld composition

Slots add independent capabilities.

Two distinct moods may fuse into one distinct ability.

Welds construct higher structures while preserving constituent identity.

## Acceptance

No element is accepted unless it exposes:

1. identity
2. authority
3. necessity
4. construction moods
5. composition
6. dependencies
7. dependents
8. slots
9. manifestations
10. footprint
11. validation
12. replay
13. recovery
14. removal
15. supersession
16. lineage
17. provenance
18. future extension

## Consequence

An implementation that produces the required capability using less authoritative substance, less duplicated machinery, and equal or greater correctness is architecturally superior.

An implementation that increases authority or footprint without proportional justified capability is rejected.
