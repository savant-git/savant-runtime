# INSTANCE STORAGE RULE

STATUS: CANON
AUTHORITY: USER DIRECTIVE

Instances are authoritative.

Folders are addressable containers.

Files are projections unless explicitly marked canon.

Every instance must expose:

- id
- kind
- type
- level
- status
- authority
- lineage
- provenance
- dependencies
- relationships
- segues
- projections
- extensions
- future_extensions

Everything that can be instanced must be instanced.
