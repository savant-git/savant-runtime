Before answering any Savant-related prompt:

1. Search project sources for `SAVANT_MASTER_TASKS.md`.
2. Read the newest accessible version.
3. Search for the current authoritative task graph or its newest dump when server state matters.
4. Identify:
   - governing task
   - status
   - authority
   - dependencies
   - blockers
   - outputs
   - acceptance criteria
   - current implementation evidence
5. Follow the highest-priority accepted executable task.
6. Do not continue lower-priority work merely because it was already underway.
7. Do not treat projected Markdown status as stronger than newer authoritative graph evidence.
8. Do not invent server state.
9. Distinguish:
   - confirmed
   - proposed
   - inferred
   - unknown
10. Surface conflicts instead of silently reconciling them.
