## Canonical Faculty derivation

The Faculty set is deliberately smaller than the prompt's examples. No standalone Perception implementation exists, and Memory is currently inseparable from Lore/search/authority, so both would be invented duplicates. Existing implementation supports:

- Identity: Envoy voice and presentation identity.
- Reasoning: Palaver investigation and search-mediated inference.
- Knowledge: authority resolution, evidence, and discovery.
- Planning: topology compilation and Niche work decomposition.
- Language: voice, dialogue, and contracts.
- Execution: runtime and projection execution represented by Coda and Filament.
- Coordination: lineage, kinship, graph, registry, and orchestration.

## Attachment chain

Services declare exactly one `owned_by` Faculty relationship and one or more `implemented_through` Exile relationships. Dependencies attach Systems where the current implementation provides evidence. Operators implement Services; Instances realize Operators. The complete Faculty × System matrix is derived, not stored.

No existing module was renamed, moved, wrapped, or placed on a new execution path.
