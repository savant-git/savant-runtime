# Phase 9 — Recursive Constitutional Reality

Reality is a constitutional object and every constitutional object is the root of a
derived constitutional universe. Recursion has no privileged depth: children and all
descendants are resolved from `contains` edges, while kind-indexed contents cover domains,
systems, faculties, services, operators, exiles, concepts, schemas, relationships,
doctrines, instances, segues, policies, and validators. No object embeds copies of its
children.

## Recursive governance and inheritance

Inheritance follows the deterministic root-to-object constitutional path. Authority and
metadata merge recursively; relationships and projection targets form sorted unique sets;
validation rules and schemas accumulate in path order. Dependencies never inherit and
remain explicit graph edges. A governing doctrine is the nearest doctrine on the lineage
path. Existing direct-query methods remain available.

## Path resolution

The path resolver performs iterative deterministic breadth-first traversal. It exposes
shortest, constitutional, governance, dependency, projection, authority, lineage,
relationship, and schema paths. Edge and neighbor ordering makes equal-length choices
stable across runs.

## Event sourcing and temporal reconstruction

Constitutional events are frozen, sequence-addressed records with a canonical SHA-256
digest. Creation, supersession, migration, schema, relationship, authority, projection,
and validation events retain evidence sufficient for replay. Temporal reconstruction is a
pure fold over immutable snapshots and events and supports sequence, timestamp, and
version inspection of lineage, authority, relationships, dependencies, and schemas.

## Bootstrap and future evolution

The bootstrap result now identifies only Reality, root domains, and core doctrines as its
recursive roots. Its former object selection remains as a compatibility view. The full
registry continues to derive from constitutional declarations, and future runtimes extend
the same object, graph, inheritance, projection, and event contracts without adding a
parallel source of truth.
