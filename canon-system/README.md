# savant dynamic canon

This package implements a fluid canon substrate.

## authority

YAML files under `authority/` are authoritative.

They may contain accepted values, provisional values, explicit unknowns, future slots, open questions, lineage, provenance, dependencies, relationships, and attachments.

## projections

Markdown under `projections/md/` is generated by `canonctl project`.

Do not edit generated Markdown as authority.

## commands

```bash
canonctl validate
canonctl project
canonctl build-db
canonctl supersede OLD_ID NEW_RECORD.yaml
```

## install

```bash
chmod +x install.sh
sudo ./install.sh /root/savant-runtime/canon-system
```

## dynamic behavior

Canon is changed by editing or adding authority records.

Unresolved fields remain `null`, with questions recorded in `open_questions`.

New versions supersede old versions without deleting history.

The SQLite database and Markdown files are deterministic projections and may be regenerated.
