# accepted decision: three primary edifices

status: accepted
accepted: 2026-09-27
authority: current user directive
scope: savant primary edifices

## decision

savant has exactly three primary edifices:

1. identity
2. utility
3. programming

no additional primary edifice exists unless established by later accepted authority.

## terminology

identity hierarchy, when naming the canonical savant identity architecture, is now identity edifice.

utility hierarchy, when naming the canonical savant utility architecture, is now utility edifice.

programming hierarchy or programming-composition hierarchy, when naming the canonical savant programming architecture, is now programming edifice.

ordinary descriptive uses of hierarchy remain hierarchy when they mean ordering, prioritization, nesting, visual prominence, authority ordering, motion ordering, typographic ordering, or another non-edifice relationship.

therefore terms such as visual hierarchy, motion hierarchy, typographic hierarchy, information hierarchy, and authority hierarchy do not establish additional savant edifices.

## preservation

earlier accepted decisions remain immutable historical authority.

historical evidence, backups, lineage, and provenance must not be rewritten merely to replace historical terminology.

current implementation and current projections must use the canonical edifice terminology where one of the three primary edifices is intended.

## supersession

this decision supersedes earlier active terminology that names identity, utility, or programming as hierarchies.

it also supersedes any earlier assertion that savant's three primary edifices are identity, scale, and content.

the substance of earlier accepted architectural decisions remains valid except where directly inconsistent with this decision.
