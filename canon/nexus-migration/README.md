# SAVANT / NEXUS CANON ENCYCLOPEDIA

## Expanded element-by-element edition

This pack intentionally replaces compressed list-only canon with **one
explanatory Markdown document per architectural element wherever the
current Nexus migration has a named/listed element**.

It includes individual documents for:

-   every edifice tier from Iota through Obelisk;
-   every one of the eight verified Nexus V15 Traits;
-   every one of the seven verified V15 typed segues;
-   historical Coalesce/Alloy/Sliver concepts and the mechanics being
    retained;
-   each major Nexus functional domain;
-   each of 25 substantial engineering enhancements;
-   each evaluated browser/library/dependency category;
-   each epistemic layer from original source through projection.

The verified V15 source defines all eight candidate Traits, their
capability lists, metadata, Nexus's transitional `quirk:nexus` identity,
and all seven segues. The newest runtime dump is broad but explicitly
excludes several oversized ownership/reference/structure artifacts, so
final live admission still requires direct repository verification.

## Canonical migration direction

``` text
V14: Slivers → Nexus Alloy
V15: Traits → Nexus Quirk
CURRENT: Motes → Traits → Quirks → Nexus Prodigal
```

No useful Coalesce engineering is discarded; redundant ontology is
retired.
