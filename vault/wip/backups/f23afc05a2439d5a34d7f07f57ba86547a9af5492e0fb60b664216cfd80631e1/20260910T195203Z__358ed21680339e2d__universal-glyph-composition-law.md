# universal glyph composition law

status: constitutional canon
authority: current user directive
accepted: 2026-09-10
scope: complete savant-runtime
mutation policy: immutable in meaning; supersede only through later accepted authority

## law

savant owns one universal shard 00.

shard 00 substantiates every glyph exactly once.

no savant-owned textual or symbolic substance may be independently
substantiated above shard 00.

every structure above shard 00 must be composed recursively from references
to instances at the immediately lower applicable composition level.

the universal construction law is:

substantiation
→ instance
→ ordered composition
→ typed segue
→ deterministic projection

never:

copy
→ duplicate
→ independently substantiate
→ manually synchronize

## universal composition

the minimum composition chain is:

glyph
→ glyph group
→ glyph-group group
→ higher bounded composition
→ reusable snippet
→ script
→ module
→ service
→ application
→ higher governed composition

semantic names for intermediate composition levels may differ where accepted
authority requires them, but their storage and composition law may not differ.

a higher-level object owns ordered references to lower-level instances.

it does not own duplicate lower-level substance.

## glyph identity

a glyph is an atomic textual or symbolic primitive.

each distinct glyph has one canonical shard-00 substantiation.

all appearances of that glyph elsewhere in savant are instances or references
to that canonical primitive.

glyph identity is separate from semantic meaning.

the same glyph may participate in unlimited compositions without duplication
of its canonical substance.

## glyph groups

a glyph group is an ordered composition of glyph-instance references.

a glyph group may represent any bounded lexical or symbolic unit required by
the owning structure.

glyph groups are content-addressable and reusable.

identical glyph groups should resolve to the same reusable structural
substance when authority and semantic scope permit.

## recursive composition

groups of glyph groups are themselves instances.

higher structures recursively compose lower structures by reference.

the same universal instance mechanics apply regardless of whether the
resulting artifact is:

- python
- shell
- json
- markdown
- html
- css
- javascript
- typescript
- sql
- configuration
- canon
- authority
- registry data
- interface data
- prompts
- generated text
- projections
- any future textual or symbolic savant artifact

language does not create a separate composition architecture.

## source files

a conventional filesystem source file is a materialized projection of its
authoritative recursive composition.

filesystem presence alone does not establish authority.

a source file may remain necessary for interpreter, compiler, operating-system,
editor, deployment, or external compatibility.

that compatibility requirement does not authorize duplicate canonical
substance.

the recursive composition remains the savant-owned structural identity.

the conventional file is its deterministic materialization.

## source ingestion

existing conventional source that predates this law is legacy material.

it is not automatically noncompliant merely because migration has not yet
occurred.

when migrated, it must be decomposed deterministically into reusable
composition instances without changing its executable or semantic behavior.

migration must preserve:

- bytes
- ordering
- encoding
- executable meaning
- authority
- lineage
- provenance
- dependencies
- dependents
- compatibility

migration must be reversible.

## source generation

new savant-owned source must be capable of being represented as recursive
composition from shard-00 glyph instances.

generation must proceed conceptually as:

canonical glyph substance
→ glyph instances
→ glyph groups
→ higher compositions
→ script composition
→ materialized compatibility file

a generator may accept ordinary text as an authoring interface only when that
text is deterministically decomposed into the universal composition before
becoming savant-owned canonical structure.

## deduplication

lower-level substance must not be duplicated when reference suffices.

content-addressed identity should be used for structurally identical immutable
compositions.

semantic identity must remain distinct from textual identity.

two structures with identical spelling may have distinct semantic identities
when authority requires it.

two semantic concepts may share textual composition without sharing semantic
identity.

## mutation

canonical lower-level substance is immutable.

changes create new composition instances.

history is preserved through lineage and supersession.

higher structures may be reprojected from changed dependencies.

destructive mutation of shared lower-level substance is forbidden.

## typed segues

relationships between instances are represented through typed segues rather
than duplicated explanatory substance where reference is sufficient.

segues must expose their source, target, type, scope, and provenance when
applicable.

## projections

conventional files, indexes, views, caches, bundles, reports, prompts, and
runtime packets are projections when derivable from authoritative composition.

derived projections must be rebuildable.

projection identity should be deterministic from authoritative inputs.

## execution

interpreters and external tools may execute conventional materialized files.

savant's internal structural identity remains the recursive composition graph.

execution receipts may reference both the composition identity and the
materialized compatibility path.

## universality

this law applies to every savant-owned script and every savant-owned artifact
that uses glyphs.

no exile, innate, portal, obelisk, rubric, cabal, application, service, module,
or future edifice receives an exemption merely because its semantic domain
differs.

## underscore and opus

underscore owns divergence, novelty pressure, anti-cliche cognition, and
latent mutation.

opus owns ai-api and model/provider orchestration.

underscore does not become an ai provider.

opus does not absorb underscore's novelty authority.

opus may instantiate underscore capability through an explicit typed segue.

underscore may transform the search topology, constraints, perspectives,
hypothesis neighborhoods, and novelty pressure of an opus orchestration.

the resulting inference remains derived.

neither model consensus nor novelty creates authority.

## invariants

- shard 00 is universal.
- glyph substance is substantiated once.
- higher structures compose instances.
- lower-level substance is not duplicated when reference suffices.
- semantic identity is separate from textual identity.
- composition is ordered where order affects meaning.
- shared substance is immutable.
- mutation creates new instances.
- lineage is preserved.
- provenance is preserved.
- authority is preserved.
- projections are rebuildable.
- filesystem presence is not authority.
- compatibility materialization does not create duplicate authority.
- every new savant textual or symbolic artifact is governed by this law.
