# Savant Miami-Dade Court Monitor

Monitors civil case `2026-115436-CC-26`, records immutable snapshots and docket
history in SQLite, downloads newly available docket documents, warns when API
units are low, and can issue Android notifications through Termux:API.

## Put the files in place with Nano

Create the independent Clerk program directory:

```bash
mkdir -p ~/clerk/sys
```

Create each file and paste its matching contents:

```bash
nano ~/clerk/sys/court_monitor.py
nano ~/clerk/sys/court-monitor.json
nano ~/clerk/sys/run-court-monitor.sh
nano ~/clerk/sys/install-court-monitor.sh
```

In Nano, save with **Ctrl+O**, press **Enter**, then exit with **Ctrl+X**.

Verify that `~/.env` contains this exact variable name:

```env
MIAMI_DADE_CLERK_API_KEY=your_private_key
```

Then install and validate without spending an API unit:

```bash
bash ~/clerk/sys/install-court-monitor.sh
```

Run the first live check:

```bash
~/clerk/sys/run-court-monitor.sh
tail -n 30 ~/clerk/logs/court-monitor.log
```

Show database status:

```bash
python3 ~/clerk/sys/court_monitor.py status \
  --config ~/clerk/sys/court-monitor.json
```

## Schedule in Termux

Install Termux:API from the same source as Termux, then:

```bash
pkg install termux-api cronie
crond
crontab -e
```

Add this line to check every six hours:

```cron
17 */6 * * * /data/data/com.termux/files/home/clerk/sys/run-court-monitor.sh
```

That schedule normally uses two requests per run plus one request for each
previously undownloaded document. At the Clerk's published price of $0.20 per
request, the baseline is about $0.40 per run or $1.60 per day.

## Data locations

- Programs/config: `~/clerk/sys/`
- Case metadata: `~/clerk/data/cases/2026-115436-CC-26/case-information/`
- Docket data: `~/clerk/data/cases/2026-115436-CC-26/dockets/`
- Original filings: `~/clerk/data/cases/2026-115436-CC-26/documents/originals/YYYY/`
- Rejected documents: `~/clerk/data/cases/2026-115436-CC-26/documents/quarantine/`
- Change notices: `~/clerk/data/cases/2026-115436-CC-26/events/`
- Database: `~/clerk/data/cases/2026-115436-CC-26/database/history.sqlite3`
- Generated exports: `~/clerk/data/cases/2026-115436-CC-26/exports/`
- Operational log: `~/clerk/logs/court-monitor.log`

Keep `~/.env`, the data directory, and downloaded filings private. Never add
them to Git.
