# SCRIPT COMPOSITION RULE

STATUS: CANON
AUTHORITY: USER DIRECTIVE

Scripts are not atomic.

A script is composed of snippets.

A snippet is composed of lines.

A line is composed of characters.

edifice:

character
→ line
→ snippet
→ script
→ engine
→ subsystem
→ system
→ application

Every script artifact must expose:

- source characters
- source lines
- source snippets
- assembled script
- generated projection path
- lineage
- provenance
- dependencies
- future extension slots

Files are projections.

The authoritative structure is the instance composition chain.
