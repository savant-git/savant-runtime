# INSTANCE PROJECTION RULE

STATUS: CANON
AUTHORITY: USER DIRECTIVE

Instances are authoritative.

Files are projections.

Scripts are projections from script instances.

Script instances are composed from snippet instances.

Snippet instances are composed from line instances.

Line instances are composed from character instances.

Every projected file must expose:

- projection id
- source instance id
- source child instances
- source segues
- source policies
- lineage
- provenance
- dependencies
- generated path
- future extension slots

Generated files may be deleted and regenerated.

Instance chains may not be deleted unless superseded by authority.
