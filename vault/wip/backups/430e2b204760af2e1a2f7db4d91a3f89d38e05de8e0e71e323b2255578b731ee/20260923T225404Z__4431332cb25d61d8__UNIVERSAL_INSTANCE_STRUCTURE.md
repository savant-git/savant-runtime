Every stable Savant element may be represented as an instance.
Every instance may compose other instances.
Every edifice level uses the same recursive structural model.
Files do not become primary architecture merely by existing.
Authority lives in authoritative primitives, instance relationships, Segues, policies, lineage, provenance, and accepted governing decisions.

## Programming edifice

```text
glyph
→ line
→ segment
→ snippet
→ script
→ engine
→ subsystem
→ system
→ application
```

`glyph` is the atomic programming-edifice level.

## Identity edifice

```text
iota
→ mote
→ trait
→ quirk
→ prodigal
→ exile
→ innate
→ portal
→ obelisk
```

Programming and identity are separate semantic axes.

## Universal properties

A stable instance supports, where applicable:

- identity;
- kind;
- type;
- level;
- version;
- status;
- authority;
- lineage;
- provenance;
- dependencies;
- dependents;
- relationships;
- composition;
- Segues;
- capabilities;
- projections;
- compatibility;
- extensions;
- attachments;
- future extensions.

No edifice type receives a fundamentally different storage model.
Only semantics, authority, relationships, composition, and legitimate facilities differ.

A directory is not inherently the instance.
A file is not inherently the instance.
A projection is not inherently the instance.
Canonical substance exists once and is composed by reference wherever possible.
