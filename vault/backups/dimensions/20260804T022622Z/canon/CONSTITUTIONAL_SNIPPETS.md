# CONSTITUTIONAL SNIPPETS
Version: 1.2.0
Status: Canonical

---

# Purpose

Snippets are the canonical implementation units of Savant.

A snippet encapsulates a single reusable capability.

Components, behaviors, scripts, and subsystems emerge through snippet composition.

A snippet shall never become a monolith.

---

# Principles

Snippets shall always be:

- atomic
- reusable
- deterministic
- composable
- replayable
- graph-addressable
- benchmarkable
- observable
- authority-aware

---

# Constitutional Law

A snippet represents exactly one canonical implementation responsibility.

When multiple responsibilities emerge, the snippet shall be decomposed.

---

# Universal Fields

Every snippet exposes:

- identifier
- canonical name
- semantic identity
- canonical purpose
- authority source
- lineage
- provenance
- version
- semantic digest

---

# Composition

Snippets compose through:

- instances
- typed segues
- parameterization
- attachment
- specialization
- validators
- policies
- projections
- composition graphs

Composition shall replace duplication.

---

# Parameterization

Behavioral variation occurs through parameters rather than copied implementations.

Parameters shall preserve:

- authority
- identity
- replay
- validation
- compatibility
- composition
- observability
- benchmarks
- determinism

---

# Specialization

Specialization extends the canonical snippet.

It never replaces it.

Specializations expose:

- parent snippet
- specialization parameters
- compatibility
- validators
- benchmarks
- lineage
- provenance
- replay compatibility
- constitutional compliance

---

# Validation

Every snippet validates:

- syntax
- semantics
- interfaces
- dependencies
- compatibility
- replay
- benchmarks
- constitutional policies
- graph integrity

---

# Evolution

Snippets evolve through:

- composition
- extension
- attachment
- parameterization
- normalization
- supersession
- benchmarking
- replay verification
- governed acceptance

Canonical identity remains stable.

---

# Benchmark Requirements

Every accepted snippet demonstrates:

- reduced duplication
- preserved behavior
- preserved replay
- improved maintainability
- improved composition
- validator compatibility
- policy compatibility
- recovery compatibility
- constitutional compliance

---

# Forbidden Operations

Snippets shall never:

- duplicate canonical logic
- duplicate authority
- bypass composition
- bypass governance
- bypass validation
- bypass replay
- conceal dependencies
- conceal interfaces
- become architectural dead ends

---

# Constitutional Guarantee

Snippets are the fundamental reusable implementation units of Savant.

Everything larger than a snippet emerges through deterministic composition.

Nothing above the snippet layer owns unique behavior that cannot itself be decomposed into reusable canonical implementations.
