# Purpose

Metadata provides standardized descriptive information for constitutional objects.

Metadata describes.

It never establishes authority.

---

# Required Metadata

Every object exposes:

- identifier
- title
- version
- authority
- classification
- lineage
- provenance
- timestamps
- semantic digest
