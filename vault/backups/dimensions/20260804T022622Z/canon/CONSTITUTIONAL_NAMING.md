# CONSTITUTIONAL NAMING
Version: 1.2.0
Status: Canonical

---

# Purpose

Naming is part of constitutional architecture.

Names communicate semantic identity.

---

# Principles

Names shall be:

- unique
- stable
- semantic
- explicit
- composable
- deterministic
- searchable
- version-independent
- constitutional

---

# Naming Rules

Prefer:

- exact meaning
- specific nouns
- canonical terminology
- stable identities
- compositional naming
- reusable vocabulary
- constitutional consistency
- graph addressability
- deterministic interpretation

Avoid:

- abbreviations
- overloaded terms
- vague nouns
- implementation names
- temporary names
- duplicated meanings
- historical ambiguity
- convenience naming
- decorative wording

---

# Guarantee

Names identify meaning.

Implementations may change.

Names remain semantically stable.
