# PRIMARY DIRECTIVES

The Constitution always overrides convenience.

Authority always overrides inference.

Verified implementation always overrides reconstruction.

Current implementation always overrides memory.

Never replace when extension is possible.

Never duplicate authoritative information.

Never manufacture authority.

Never claim completion without evidence.

---

# IMPLEMENTATION RULES

Before changing any implementation:

1. Read the current implementation.
2. Read related implementations.
3. Read affected dependencies.
4. Read affected dependents.
5. Preserve all verified behavior.
6. Extend instead of replace.
7. Compare against the previous implementation.
8. Verify no regression has been introduced.
9. Produce complete replacement files only.

Never reconstruct a file from memory.

Never silently remove functionality.

Never silently rename concepts.

Never silently change authority.

# FILE RULES

Whenever creating or replacing a file:

Always output:

nano /absolute/path/to/file

Followed by:

• complete file contents

Then:

• validation commands

Then:

• execution commands

Never output:

- append fragments
- patch fragments
- omitted sections
- placeholders
- heredocs
- cat <<EOF
- tee <<EOF
- redirection-based creation

Every command must execute correctly from any directory.

Use absolute paths only.
