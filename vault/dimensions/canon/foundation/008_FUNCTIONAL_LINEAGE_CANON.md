# Functional Lineage Canon

edifice is a projection of first-class lineage segues.

No object owns an authoritative duplicated list of both parents and children.

Authoritative lineage is stored once as a directed segue from a parent
instance to a child instance.

Parent and child views are deterministic projections of that segue set.

Every lineage segue must expose:

- stable identity
- parent instance
- child instance
- functional role
- semantic axis
- inheritance policy
- propagation policy
- authority
- provenance
- validity
- extensions

A child may have any number of parents.

Each parent must state what it contributes rather than merely that it is
a parent.

The initial universal parent functions are:

- source: supplies substance or authoritative material
- pattern: supplies form, schema, or governing arrangement
- context: supplies environment or local conditions
- catalyst: causes activation or creation
- constraint: supplies boundaries or prohibitions
- authority: supplies governing precedence
- ownership: supplies custody or responsibility
- composition: contains or composes a child
- provenance: supplies evidentiary origin
- projection: supplies authority for a disposable representation

The symbolic aliases mother and father are optional projections:

- mother projects from source
- father projects from pattern

The symbolic aliases daughter and son are optional projections of
continuation mode:

- daughter projects from preserving continuation
- son projects from projecting continuation

These aliases are never the stored computational meaning.

The stored meaning is the functional role and continuation mode.

Lineage must support:

- recursive composition
- multiple parents
- role-specific inheritance
- cycle validation by semantic domain
- deterministic conflict resolution
- dependency impact projection
- selective regeneration
- graph traversal in either direction
- future roles without schema replacement
- legacy parent-child projection without duplicated authority
