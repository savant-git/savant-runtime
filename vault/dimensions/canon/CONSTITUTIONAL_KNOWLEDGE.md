# CONSTITUTIONAL KNOWLEDGE
Version: 1.2.0
Status: Canonical

---

# Purpose

Knowledge defines everything the constitutional system knows.

Knowledge is governed by authority.

Knowledge is never inferred into authority.

---

# Knowledge Classes

- authority
- evidence
- observation
- inference
- estimate
- proposal
- implementation
- projection
- history

---

# Knowledge Laws

Knowledge shall:

- expose authority
- expose confidence
- expose provenance
- expose lineage
- expose dependencies
- expose observations
- expose replay
- expose validators
- expose semantic identity

---

# Constitutional Guarantee

Knowledge remains permanently distinguishable from authority.
