# CONSTITUTIONAL MANIFESTS
Version: 1.2.0
Status: Canonical

---

# Purpose

Manifests describe the complete composition of constitutional artifacts.

They enable deterministic reconstruction.

---

# Manifest Contents

Every manifest records:

- identity
- version
- authority digest
- dependencies
- validators
- policies
- projections
- replay compatibility
- integrity metadata

---

# Guarantee

Manifests remain derived artifacts.

They never become authority.
