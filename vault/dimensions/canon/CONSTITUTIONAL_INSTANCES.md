# CONSTITUTIONAL INSTANCES
Version: 1.2.0
Status: Canonical

---

# Purpose

Instances are the primary compositional primitive of Savant.

Only atomic characters are directly substantiated.

Everything above the atomic level exists only as reusable instances connected through typed segues.

The instance system eliminates duplication while maximizing composability, determinism, and extensibility.

---

# Principles

Instances shall always be:

- canonical
- reusable
- deterministic
- composable
- replayable
- graph-addressable
- observable
- recoverable
- authority-aware

---

# Constitutional Law

Direct substantiation is permitted only for atomic characters.

Every higher object shall be an instance.

Copies are prohibited when an instance may be referenced.

---

# Universal Instance Fields

Every instance exposes:

- identifier
- instance class
- canonical source
- semantic identity
- authority source
- lineage
- provenance
- version
- semantic digest

---

# Composition Rules

Instances may:

- compose
- parameterize
- attach
- inherit behavior
- expose interfaces
- expose validators
- expose dependencies
- expose observations
- expose projections

Instances shall never duplicate authoritative substance.

---

# Parameterization

Instances are specialized through parameters.

Parameterization shall:

- preserve identity
- preserve authority
- preserve replay
- preserve lineage
- preserve provenance
- preserve normalization
- preserve compatibility
- preserve validation
- preserve composition

---

# Attachment

Instances support non-destructive attachment.

Attachments may introduce:

- metadata
- validators
- policies
- observations
- projections
- compatibility
- documentation
- configuration
- extensions

Attachments shall never mutate canonical substance.

---

# Reuse

Reuse shall always be preferred over:

- duplication
- cloning
- specialization by copying
- parallel implementations
- manual synchronization
- repeated validation
- repeated schemas
- repeated policies
- repeated maintenance

---

# Validation

Every instance validates:

- canonical source
- authority
- composition
- dependency integrity
- replay compatibility
- constitutional compliance
- parameter correctness
- attachment correctness
- semantic consistency

---

# Evolution

Evolution occurs by:

- extending instances
- composing instances
- attaching instances
- parameterizing instances
- superseding instances
- migrating instances
- benchmarking instances
- validating instances
- replaying instances

Canonical substance remains stable.

---

# Forbidden Operations

Instances shall never:

- duplicate authority
- duplicate canonical substance
- bypass typed segues
- bypass governance
- bypass validation
- manufacture lineage
- manufacture provenance
- conceal dependencies
- become isolated from the graph

---

# Constitutional Guarantee

Every Savant capability above the atomic character level is an instance.

Composition replaces duplication.

Parameterization replaces cloning.

Attachments replace destructive mutation.

The instance graph is the primary mechanism through which Savant evolves while preserving constitutional authority.
