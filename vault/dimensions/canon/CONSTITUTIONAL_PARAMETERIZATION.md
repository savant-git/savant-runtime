# CONSTITUTIONAL PARAMETERIZATION
Version: 1.2.0
Status: Canonical

---

# Purpose

Variation shall emerge from parameterization rather than duplication.

---

# Parameter Rules

Parameters may alter:

- configuration
- execution
- composition
- scheduling
- compatibility
- presentation
- validation
- projection
- observation

Parameters never alter canonical identity.

---

# Constitutional Guarantee

Parameterization replaces cloning.
