# CONSTITUTIONAL DEPENDENCIES
Version: 1.2.0
Status: Canonical

---

# Purpose

Dependencies define constitutional ordering and propagation.

---

# Principles

Dependencies shall be:

- explicit
- typed
- deterministic
- acyclic
- replayable
- observable
- validated
- composable
- constitutional

---

# Every Dependency Exposes

- source
- destination
- dependency type
- ordering
- propagation rules
- validator
- benchmark
- lineage
- provenance

---

# Guarantee

Dependencies determine execution.

They never determine authority.
