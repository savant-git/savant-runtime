# CONSTITUTIONAL STATE MACHINE
Version: 1.2.0
Status: Canonical

---

# Purpose

Defines every valid constitutional state transition.

States are derived.

They are never manually asserted.

---

# Canonical States

- proposed
- admitted
- validated
- benchmarked
- replayed
- accepted
- superseded
- archived
- recovered

---

# Transition Rules

Transitions require:

- evidence
- validation
- replay
- benchmarks
- governance
- receipts
- graph updates
- integrity verification
- constitutional compliance

Illegal transitions fail automatically.

---

# Guarantee

State evolution remains deterministic and replayable.
