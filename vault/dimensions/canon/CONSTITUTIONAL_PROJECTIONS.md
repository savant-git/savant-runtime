# CONSTITUTIONAL PROJECTIONS
Version: 1.2.0
Status: Canonical

---

# Purpose

Authoritative information is stored exactly once.

Every other representation is a deterministic projection.

Projections are disposable.

Authority is not.

---

# Projection Principles

Every projection shall be:

- deterministic
- reproducible
- disposable
- replayable
- versioned
- observable
- auditable
- recoverable
- regenerable

A projection never becomes authority.

---

# Authoritative Sources

Only these may produce projections:

- authoritative graph
- accepted decisions
- constitutional canon
- admitted evidence
- verified implementation
- accepted schemas
- accepted policies
- accepted validators
- accepted runtime metadata

# Projection Rules

Every projection must:

- preserve authority
- preserve meaning
- preserve lineage
- preserve provenance
- preserve semantic identity
- preserve dependency relationships
- preserve supersession history
- preserve compatibility
- preserve replayability

---

# Projection Lifecycle

Every projection follows:

1. Resolve authority.
2. Validate authority.
3. Build semantic model.
4. Generate projection.
5. Validate projection.
6. Compute digest.
7. Register manifest.
8. Verify replay.
9. Publish projection.

---

# Projection Invalidations

A projection becomes stale when:

- authority changes
- accepted decisions change
- schema changes
- policy changes
- implementation changes
- dependency changes
- evidence changes
- validator changes
- replay changes

Stale projections are regenerated automatically.

---

# Projection Constraints

A projection shall never:

- introduce authority
- delete authority
- reinterpret authority
- merge conflicting authority
- hide conflicts
- hide supersession
- manufacture lineage
- manufacture provenance
- bypass constitutional policy

- validation status

# Projection Verification

Every projection must pass:

- schema validation
- semantic validation
- dependency validation
- integrity validation
- replay verification
- benchmark comparison
- constitutional validation
- policy validation
- manifest verification

---

# Projection Regeneration

Regeneration shall:

- preserve authority
- preserve history
- preserve identifiers
- preserve lineage
- preserve provenance
- refresh derived state
- refresh manifests
- refresh integrity trees
- refresh replay artifacts

---

# Constitutional Guarantee

Every projection is disposable.

Every authoritative fact is recoverable.

Deleting every projection must never destroy the authoritative graph.
